# 🏥 Sistema de Agendamento para Clínicas Médicas

## 📌 Sobre o projeto

Nosso projeto é um sistema de agendamento para clínicas médicas.

O objetivo é facilitar a organização dos pacientes e das consultas,
evitando problemas com horários e ajudando no trabalho dos profissionais.

## 👥 Usuários

- Pacientes
- Médicos
- Funcionários da clínica

## ⚙️ Funcionalidades

- Cadastro de pacientes
- Agendamento de consultas
- Remarcação de consultas
- Cancelamento de consultas
- Visualização da agenda médica

## 🗄️ Banco de Dados

Foi criada a tabela `Paciente` com os seguintes campos:

- `id_paciente`
- `nome`
- `telefone`
- `data_nascimento`
- `endereco`

## 🔄 CRUD

O banco de dados utiliza os principais comandos SQL:

- **INSERT** → cadastrar informações
- **SELECT** → consultar informações
- **UPDATE** → alterar informações
- **DELETE** → excluir informações

## 🎯 Objetivo

O sistema busca melhorar a organização da clínica,
reduzir erros e facilitar o gerenciamento das consultas.
